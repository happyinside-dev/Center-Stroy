# Ассеты Центр-Строй

Открыть `index.html` напрямую в браузере. Это просмотр материалов второго этапа, не макет и не приложение. npm-проект появится на этапе разработки.

## Состав

- `brand/wordmark-orange.svg` — авторская векторная интерпретация надписи с предоставленной вывески. Все буквы — геометрия, файл не зависит от шрифта. Не установлено название исходного шрифта; точное совпадение с вывеской не заявляется.
- `brand/wordmark-currentcolor.svg` — та же геометрия для inline SVG с управляемым цветом. При использовании через img currentColor не наследуется от внешнего HTML.
- `brand/tools-pattern.svg` — прозрачный повторяющийся узор, белые силуэты инструментов с непрозрачностью 5%. Не накладывать opacity 5% повторно. Для другого размера плитки корректировать pattern, не растягивать силуэты.
- `brand/tool-wrench.svg`, `tool-hammer.svg`, `tool-screwdriver.svg` — отдельно отрисованные гаечный ключ, молоток-гвоздодёр и шлицевая отвёртка. Вытянутые сплошные силуэты без декоративных внутренних деталей, рукоятки утолщены примерно на 20%, окончания согласованно скруглены. В парах общий центр пересечения, угол 76° и одинаковый размер композиции; у пары ключ/молоток головы направлены в противоположные стороны для равновесия. Крупный просмотр — `previews/tools-detail.png`, вся система пар — `previews/tools-pairs.png`.
- `brand/shopfront-reference.png` — копия предоставленного снимка вывески.
- `brand/menu-mascot.webp` — оптимизированная версия предоставленного изображения мастера, без изменения композиции. Полный исходник сохранён рядом в assets.
- `brand/tokens.json` — начальные цвета, 16px скругление и роли шрифтов. Точные значения можно менять централизованно на этапе макета.
- `fonts/GolosText-Variable.ttf` — Golos Text, кириллица, веса 400–900. Локальный файл из официального Google Fonts: https://github.com/google/fonts/tree/main/ofl/golostext . Лицензия SIL OFL: `fonts/GolosText-OFL.txt`.
- `icons/*.svg` — 30 иконок Lucide, размерная сетка 24, stroke 2. `sprite.svg` объединяет их в symbol. Источники: https://github.com/lucide-icons/lucide и закреплённый пакет https://unpkg.com/lucide-static@0.468.0/ . Лицензии ISC/MIT сохранены в `icons/LICENSE`.
- `catalog/photos/` — 100 подготовленных предметных фотографий 960×960.
- `catalog/thumbs/` — 100 миниатюр 360×360, использовать в сетке; большие файлы — в подробностях.
- `catalog/manifest.json` и `.csv` — категории, производитель, исходное название, артикул, ссылки на страницу и снимок, локальные пути, технические сведения и статус прав.
- `previews/catalog-01.jpg`…`catalog-04.jpg` — четыре контактных листа; `brand-board.png` — проверка надписи и фона; `type-and-colors.png` — кириллица и палитра.

## Восемь категорий

Электроинструмент (16), ручной инструмент (20), измерение и разметка (12), оснастка (12), крепёж (12), краски и грунтовки (10), герметики/пены/клеи (10), хранение инструмента (8).

Это набор изображений для последующей сборки каталога, а не обещание реального ассортимента магазина. Товары представлены DeWALT, STANLEY, Soudal и V33. Производители и модели нужны для точного соответствия фотографии. Нельзя переименовывать изображённый инструмент в модель другого производителя, перекрашивать товар для вымышленных вариантов или приписывать отсутствующую комплектацию. На этапе подготовки данных родственные фасовки/размеры/комплектации объединяются в варианты; реальное количество товарных семейств может отличаться от количества фотографий.

## Источники фотографий и права

Предметные фотографии взяты с открытых страниц официальных каталогов:

- https://www.stanleytools.com/en-us/products/hand-tools
- https://www.stanleytools.com/en-us/products/storage-organization
- https://www.dewalt.com/en-us/products/power-tools
- https://www.soudal.co.uk/pro/products
- https://www.v33.co.uk/renovation-cupboard-worktop/

Ссылки на конкретные изображения и страницы перечислены в реестре. Это авторские материалы производителей, **не свободно лицензированный фотосток**. Скачивание не устанавливает разрешение на публичное/коммерческое повторное использование. Для публикации следует подтвердить право использования либо заменить снимки. Фотографии не доказывают наличие товаров у Центр-Строя. Права на предоставленный пользователем исходный рисунок отдельно не устанавливались.

Фотографии пропорционально вписаны на белый квадрат, без изменения цвета и предметного содержимого. Для узких свёрл и тюбиков оценивается разрешение по длинной стороне. Некоторые изображения комплектов содержат сумку, аккумуляторы и зарядное устройство — это необходимо сохранить в названии/комплектации.

## Проверка

Все 100 фотографий и миниатюр декодированы, размеры проверены, побайтовые дубли исключены. Четыре контактных листа просмотрены. Контраст графитового текста на оранжевом — 6,04:1; яркий оранжевый на белом — 2,61:1, поэтому для небольшого текста добавлен `orangeInk` #b94c00. Окончательная оценка размеров, контраста состояний и анимации производится на макете и в браузере.

## Воспроизведение

- `python scripts/prepare_brand.py` — SVG, токены, шрифт и иконки; при наличии локальных файлов повторная загрузка не нужна.
- `python scripts/prepare_catalog_photos.py` — повторный сбор из официальных каталогов с кэшем. Требует интернет, curl и Pillow; цены/остатки не создаёт.
- `python scripts/build_asset_index.py` — проверка файлов, CSV, контрольные суммы и локальный просмотр.

`catalog/cache/` — технический кэш исходных HTML и изображений, не включать в публичную сборку. Согласованные продуктовые решения — `../PRODUCT.md` и `../docs/design-decisions.md`. Следующий этап — визуальный макет; разработка сайта ещё не начата.
