# Центр-Строй

Демонстрационный интернет-магазин строительного магазина. React + TypeScript + Vite. Бэкенд для работы демо не нужен.

## Запуск

Node.js 22.12+ (проверено на 22.23.4), npm.

```sh
npm install
npm run dev
```

Открыть адрес из терминала, по умолчанию http://localhost:5173. Перед запуском необходимые локальные ассеты автоматически копируются в `public/media/`.

```sh
npm test
npm run build
npm run preview
```

`npm run build` создаёт готовую папку `dist/`. Её содержимое можно разместить на обычном статическом сервере, в том числе в подкаталоге. Сервер Node.js для публикации не требуется; конфигурация SPA fallback не нужна — разделы открываются в окнах, а не по серверным маршрутам. Для локальных аккаунтов используйте localhost или HTTPS: пароль обрабатывается через Web Crypto.

## Что реализовано

- Графитовый Hero с авторской SVG-надписью и орнаментом; один поиск плавно перемещается в закреплённый хедер при прокрутке. При отключённой анимации переход упрощён.
- 93 модели, 100 вариантов, восемь категорий и локальные фотографии. Разные комплектации одной модели объединены: в том числе лобзик DCS331, дрель DCD800, шлифмашина DCW210 и размеры свёрл DWAWDEA.
- Поиск по названию, артикулу и характеристикам; категории, производитель, цена, наличие и комплектация. Условия применяются к одному варианту, поэтому цена и фото в выдаче соответствуют результату поиска.
- Сортировка по цене, названию и наличию; просмотр порциями по 24 товара. Фильтры слева на компьютере, скрываемая панель, мобильное окно с общей сортировкой. Когда верх каталога ушёл за экран, кнопка параметров доступна в хедере.
- Подробности товара, фото, характеристики, выбор варианта. Быстрое добавление открывает варианты при необходимости; счётчик конкретного варианта ограничен остатком. В карточке с несколькими вариантами отображается суммарное количество.
- Корзина, оформление и успех — шаги одного большого окна с блюром. Демо оплата без карты и списания денег. На телефоне блок покупки товара и оформление закреплены внизу окна.
- Гостевой заказ, регистрация и вход по email и тестовому паролю, профиль, автозаполнение, другой получатель и история аккаунта. Пароль сохраняется в виде PBKDF2-хеша с отдельной солью. Демо не является защищённой серверной авторизацией.
- Самовывоз и доставка по Севастополю и Крыму. Обязательные имя, телефон и email; отдельный выключенный чекбокс рассылки. Письма и SMS не отправляются.
- Демо админка: добавление и редактирование товаров, цены и остатки вариантов, характеристики, фото по ссылке и с устройства, главная фотография варианта и галерея. Архивирование с восстановлением. Товары и цены в старом заказе сохраняются снимком.
- Просмотр заказов и смена статусов, отмена с однократным возвратом остатков. Завершённый или отменённый заказ нельзя произвольно возобновить.
- Экспорт демо данных и сброс с подтверждением. Вход в панель — в меню и внизу страницы, ссылка «Демо админка». Отдельный пароль администратора не нужен: это открытая демонстрационная панель.

## Доставка и OpenRouteService

Без настройки ключа всё работает локально: выбирается населённый пункт, расстояние берётся из демонстрационной таблицы, цена считается как `ceil(км × 2 ₽)`. Адрес не влияет на табличное расстояние; интерфейс прямо отмечает условность расчёта. Для другого населённого пункта предусмотрена отдельная строка с условным расстоянием.

Для подключения маршрутизатора:

1. Создать бесплатный API-ключ: https://account.heigit.org/ .
2. Скопировать `.env.example` в `.env.local`.
3. Указать `VITE_ORS_API_KEY` и перезапустить `npm run dev` либо пересобрать сайт.

Используются актуальные адреса после миграции 2026 года:

- `https://api.heigit.org/pelias/v1/search`
- `https://api.heigit.org/openrouteservice/v2/directions/driving-car`

Поиск ограничен прямоугольником Крыма. Стартовая координата магазина задана в `src/delivery.ts` на основе исходной ссылки; для реальной доставки её нужно сверить с точным входом магазина. Полученное расстояние округляется вверх до целого километра. При отказе сервиса или ненайденном адресе интерфейс переключается на явно обозначенный условный расчёт. Изменение адреса аннулирует предыдущую цену.

Ключ `VITE_*` виден в браузере — для демо нужен отдельный ключ. В случае необходимости скрытия ключа можно подключить совместимый серверный прокси через `VITE_ORS_BASE_URL`. Отдельный бэкенд не является обязательной частью текущего проекта.

Проверены актуальные конечные точки и наличие CORS-заголовка; успешный живой маршрут по Крыму без пользовательского ключа проверить нельзя. Интеграция проверена тестами с ответами геокодера и маршрутизатора. Условия миграции: https://ask.openrouteservice.org/t/deprecating-api-openrouteservice-org-in-favour-of-api-heigit-org/7912/ .

## Хранение данных

Каталог, варианты, корзина, локальные аккаунты и заказы — `localStorage`, ключ `centr-stroy-demo-v1`. Загруженные фотографии — IndexedDB `centr-stroy-images`, в данных хранится ссылка `idb:…`.

Данные доступны только в том браузере и на том origin, где созданы; localhost, IP-адрес и опубликованный домен имеют разные хранилища. Изменения между вкладками одного origin обновляются. Очистка данных сайта удаляет демо. Экспорт JSON не включает бинарные фотографии из IndexedDB и предназначен для просмотра/резервирования структурированных данных, не для полного переноса проекта между устройствами.

Используйте вымышленные контакты и отдельные тестовые пароли. Демо заказы не передаются реальному магазину.

## Ассеты и изменение дизайна

Исходники и источники — `assets/README.md`, просмотр — `assets/index.html`. Фотографии производителей не объявляются свободным фотостоком; условия использования описаны в реестре. Цена и наличие демонстрационные.

Основные CSS-параметры находятся в `:root` файла `src/styles.css`: `--radius: 16px`, графит, оранжевый, поверхности и высота хедера. SVG-надпись и орнамент — `assets/brand/`, генератор — `scripts/prepare_brand.py`. После изменения исходников `npm run dev` или `npm run build` синхронизирует ассеты.

## Проверка

15 автоматических проверок: количество и варианты корзины, списание остатков, неизменяемость заказа, запрет заказа архивного/недоступного товара, однократная отмена, доставка, поиск по комбинации, хеширование пароля и ответы маршрутизатора.

В браузере проверены гостевая покупка с телефона, регистрация и автозаполнение, доставка, история, отмена в админке с возвратом остатков, создание/архивирование/возврат товара, загрузка фото в IndexedDB и её сохранение после перезагрузки, покупка двух разных комплектаций, фильтры и ширины 320/390/768/1024/1440 px. Позиция каталога сохраняется после закрытия окна товара.
